# Execution Telemetry Handoffs

Every session working on the provider-neutral execution telemetry plan must rewrite `latest.md` before stopping and also create a dated handoff file named `YYYY-MM-DD-slice-<id>.md`.

Start each new session by reading:

1. `AGENTS.md`
2. `docs/execution-telemetry/handoffs/latest.md`
3. `docs/execution-telemetry/implementation-status.md`
4. `docs/execution-telemetry/decisions.md`
5. The active slice instructions
6. Files named by the latest handoff
