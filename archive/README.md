# Archive

This directory holds non-core material moved out of the repository root during
the BMUX organization pass.

Contents here are not deleted. They are retained for reference until a later
pass either restores them into an active area, documents them as examples, or
removes them with evidence that they are obsolete.

- `Prototypes/`: standalone prototype projects.
- `dogfood-fixtures/`: manual dogfood fixtures for local config behavior.
